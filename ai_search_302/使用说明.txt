查看进度：
  python -B .\ai_search_302\monitor_302.py --watch
  Ctrl+C只退出监控，后台采集继续。

停止新增请求：
  python -B .\ai_search_302\monitor_302.py --stop
  已在进行的请求会先保存。

断点续跑：
  python -B .\ai_search_302\collect_302.py run "本轮采集目录" --retry-failed
  已完成回答跳过；接口失败另存重试结果，原记录保留。

创建新一轮任务：
  python -B .\ai_search_302\collect_302.py prepare --cards ".\新闻来源整理_2026-11-13\新闻卡片.json"
  使用上面的续跑命令启动返回的目录。

保留的脚本：
  monitor_302.py      唯一的进度监控入口
  collect_302.py      批量采集与断点续跑
  watchdog_302.py     独立守护，进程意外退出后续跑
  search_302.py       API、问题读取与结果处理的公共模块

outputs/本轮目录：
  answers/           回答、平台来源、用量等JSON

相对时间以本轮运行日的北京时间为准；自然回答由脚本保存为JSON。
“有正文与来源”只说明结构完整，事实仍需人工核查。
监控检查运行锁与心跳；超过60秒无活动显示停滞，进程退出显示中断。
